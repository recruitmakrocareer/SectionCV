# Makro Spot the Difference — 3 Photo Levels

เกมจับผิดภาพเสมือนจริงในซูเปอร์มาร์เก็ต 3 ด่าน ด่านละ 5 จุด รวม 15 จุด เล่นด้วยเมาส์หรือแตะได้ทั้งสองภาพ

เว็บสำหรับระบบผู้เล่น: [Cloudflare Worker](https://sectioncv.recruitcpaxtramakro.workers.dev/)

เล่นแบบฝึกซ้อม: https://recruitmakrocareer.github.io/SectionCV/

## เพิ่มระบบผู้เล่นและอันดับ

หน้าเริ่มเกมแสดงเป็นป๊อปอัปทันที กดผิดเพิ่มเวลาจัดอันดับครั้งละ 5 วินาที โดยไม่เพิ่มเวลาที่เหลือให้เล่น

ระบบมี LINE Login, แบบฟอร์มชื่อ/เบอร์ติดต่อ, อันดับผู้เล่นทั้งหมดแบ่งหน้าละ 10 คน และหน้าข้อมูลผู้เล่นสำหรับผู้ดูแลพร้อมส่งออก CSV การตั้งค่า LINE และ D1 อยู่ในคู่มือติดตั้ง เว็บ GitHub Pages ให้เล่นแบบฝึกซ้อม ไม่แสดงสถิติจำลองหรือเก็บข้อมูลส่วนตัวไว้เฉพาะเครื่อง

กติกาใหม่ให้เวลาภาพละ **90 วินาที** นับถอยหลังต่อเนื่อง มีนาฬิกาขนาดใหญ่และแถบเวลาเปลี่ยนสีเมื่อใกล้หมดเวลา เมื่อพบครบ 5 จุดหรือหมดเวลาจะเก็บผลด่านนั้นและเริ่มด่านถัดไปอัตโนมัติ เมื่อจบ 3 ด่านแสดงป๊อปอัปสรุปจำนวนจุด เวลา โทษกดผิด ผลแต่ละด่าน อันดับของตัวเอง และสถิติผู้เล่นทั้งหมด จัดอันดับจากจำนวนจุดมากที่สุดก่อน แล้วใช้เวลารวมโทษกดผิดตัดสินเมื่อพบเท่ากัน

รอบใหม่ใช้ `rulesVersion: 2` และเก็บความคืบหน้าในคอลัมน์ `runs.found` เดิม ไม่ต้องเพิ่มตารางหรือกรอกการตั้งค่าใหม่ ผลกติกาเดิมยังอยู่ในประวัติ แต่ไม่นำมาเทียบอันดับกับกติกา 90 วินาที

**สถิติของฉัน** แสดงเวลาที่ดีที่สุด อันดับของผู้เล่นจากทุกคน จำนวนรอบที่เล่นครบ 3 ด่าน และประวัติ 10 รอบล่าสุด รวมรอบที่เล่นไม่ครบ เปิดได้จากเมนูหลัก ป๊อปอัปเริ่มเกม และหน้าผลเมื่อเล่นครบ 3 ด่าน จึงดูผลได้แม้ไม่ติด 10 อันดับแรกหรือโหลดหน้าใหม่ โดยเข้าสู่ระบบด้วย LINE บัญชีเดิม ข้อมูลมาจาก `GET /api/me/stats` ซึ่งอ่านได้เฉพาะเจ้าของเซสชัน ไม่มีเบอร์โทรหรือ LINE ID ในผลตอบกลับนี้

การเริ่มเกมและการยืนยันว่าบันทึกสำเร็จไม่รอการโหลดตารางอันดับหรือประวัติ ปุ่มเล่นใหม่รอให้ส่งผลเสร็จก่อน และหากบันทึกไม่สำเร็จยังมีปุ่มลองบันทึกอีกครั้ง สถิติที่แสดงหลังบันทึกใช้เวลาที่เซิร์ฟเวอร์ยืนยัน

ดูขั้นตอนเปิดใช้งานและข้อกำหนดการเก็บข้อมูลใน [SETUP-LINE.md](SETUP-LINE.md)

เลือกใช้ **Cloudflare Workers Free + D1 Free** ตามที่ผู้ดูแลต้องการ ไม่มีค่าเช่าเครื่องรายเดือนและใช้ URL `workers.dev` ที่ให้ฟรี ไฟล์ [wrangler.json](wrangler.json) ใช้ชื่อ `sectioncv`, Database ID ของ `makro-player-data` และ `APP_ORIGIN` ของ Worker แล้ว ภาพ D1 Studio ของผู้ดูแลยืนยันว่ามีครบ 5 ตารางและ 5 ดัชนี การ deploy ครั้งต่อไปใช้ `main` กับ `npm run deploy` ซึ่งรัน migration ที่สร้างซ้ำได้ ก่อนเปิดรับผู้เล่นจริงต้องกรอก Channel Secret และรายชื่อผู้ดูแลที่โฮสต์ พร้อมตั้ง Callback URL ใน LINE ดู [วิธีติดตั้งแบบไม่มีค่าใช้จ่าย](SETUP-LINE.md)

แพ็กเกจ Free มีโควตา API 100,000 คำขอต่อวัน และฐานข้อมูลนี้สูงสุด 500 MB ไม่อัปเกรดเป็น Paid เพื่อรองรับการใช้งานเกินโควตา ดูขีดจำกัดการอ่าน/เขียนและแหล่งข้อมูลในคู่มือติดตั้ง

## ด่านในเกม

1. **โซนผักและผลไม้** — สังเกตความต่างของผลไม้และผักในแผงสินค้า
2. **มุมเบเกอรี่อบสด** — สังเกตรอยบนขนมและรายละเอียดของหน้าขนม
3. **ชั้นเครื่องปรุงและของแห้ง** — หารายละเอียดเล็ก ๆ ท่ามกลางขวดและกระปุกที่คล้ายกัน

ภาพเป็นภาพเสมือนจริงที่สร้างขึ้นสำหรับเกมด้วย Imagegen ไม่ใช่ภาพการ์ตูน

## วิธีเล่น

- รอภาพพร้อมแล้วกด **เริ่มเกม** แต่ละด่านมีเวลา 1 นาที 30 วินาที และคำใบ้ 2 ครั้ง
- แตะจุดต่างในภาพใดก็ได้ คะแนนเดียวกันจะนับเพียงครั้งเดียว และวงคำตอบจะแสดงทั้งสองภาพ
- พบครบ 5 จุดหรือหมดเวลาแล้วไปด่านถัดไปอัตโนมัติหลังข้อความเตรียมตัว 2 วินาที
- เก็บจำนวนจุดที่หาได้แม้ไม่ครบ เมื่อจบด่านที่ 3 จะบันทึกผลและเปิดป๊อปอัปสถิติ
- ปุ่ม **เริ่มใหม่ทั้ง 3 ด่าน** เริ่มเกมใหม่ตั้งแต่ด่านแรก
- เวลานับถอยหลังต่อเนื่อง ไม่มีการหยุดพักเมื่อสลับไปแอปอื่น
- บนมือถือใช้สองนิ้วซูมหน้าเกมเพื่อดูรายละเอียดได้
- ปุ่มเสียงเปิดเสียงเอฟเฟกต์จริง หากอุปกรณ์ไม่รองรับเสียงยังเล่นเกมได้ตามปกติ

ภาพต้องโหลดครบก่อนเริ่มนับเวลา หากภาพโหลดไม่สำเร็จจะมีปุ่มลองโหลดอีกครั้ง

## เปิดจากเครื่อง

- Windows: ดับเบิลคลิก `start.bat`
- macOS / Linux: รัน `./start.sh`
- ทุกระบบ: เปิด `index.html` ด้วยเบราว์เซอร์ได้โดยตรง โดยเก็บไฟล์อื่นและโฟลเดอร์ `assets/` ไว้ด้วยกัน

ไม่ต้องเปิดเซิร์ฟเวอร์หรือใช้ Python ฟอนต์ออนไลน์มีฟอนต์สำรองของเครื่อง

## การทดสอบและเผยแพร่

ใช้ Node.js 24 ขึ้นไปเฉพาะสำหรับงานพัฒนา:

```bash
npm ci --ignore-scripts
npm test
npm run build
```

ชุดทดสอบใช้ DOM จำลองและนาฬิกาควบคุม ตรวจการโหลดภาพ/ลองใหม่ การเล่นครบ 3 ด่าน การผ่านด่านอัตโนมัติ การนับเวลาขณะสลับแอป การเก็บคะแนนเมื่อหมดเวลา ป๊อปอัปผล อันดับนอกหน้าแรก การเริ่มเกมใหม่ คำใบ้ เสียง คีย์บอร์ด และตำแหน่งแตะหลายขนาดหน้าจอ การทดสอบนี้ไม่จำลองการวาดภาพหรือฮาร์ดแวร์เสียงของอุปกรณ์จริง

`levels.js` กำหนดภาพและตำแหน่ง 5 จุดของแต่ละด่าน ภาพทั้งสองฝั่งใช้ภาพต้นฉบับเดียวกัน แล้วแสดงภาพที่แก้ไขเฉพาะ 5 บริเวณด้วย mask ขอบนุ่ม เพื่อป้องกันรายละเอียดอื่นจากการสร้างภาพกลายเป็นจุดต่างนอกเกม

`image-generation.json` เก็บ prompt และข้อมูลอ้างอิงของภาพสำหรับแก้ไขต่อ โดยไม่ได้รวมในไฟล์เผยแพร่

ชุดทดสอบ Cloudflare ใช้ Miniflare/workerd และ D1 จริงในเครื่อง ตรวจ OAuth จำลอง, คำขอพร้อมกัน, การบันทึกซ้ำ, สิทธิ์ข้อมูลส่วนตัว, การเล่นผ่านหน้าเกมครบสามด่าน และข้อมูลคงอยู่หลังเริ่มระบบใหม่ ยังต้องทดสอบ LINE จริงก่อนเปิดกิจกรรม

`npm run check:worker` ตรวจชุดเผยแพร่ Cloudflare โดยไม่สร้างบริการหรือใช้ข้อมูลจริง

`npm run build` สร้าง `_site/` ใหม่จากรายการไฟล์เกมและภาพที่อนุญาตเท่านั้น และรักษาลิงก์เกมจับคู่เดิมที่ `memory-game/` กับ `docs/memory-game/`

Workflow `Deploy Makro game to GitHub Pages` รันชุดทดสอบก่อนเผยแพร่เมื่อ push ไปยัง `main`, `work` หรือ `codex/create-makro-sprite-spot-the-difference-game` ส่วน `Verify Makro game` ตรวจใน Pull Request ด้วย
