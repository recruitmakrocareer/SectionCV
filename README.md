# Makro Spot the Difference

เกมจับผิดภาพแม็คโคร หาจุดต่าง 5 จุดให้ครบภายใน 2 นาที เล่นด้วยเมาส์หรือแตะหน้าจอได้ทั้งสองภาพ

เล่นออนไลน์: https://recruitmakrocareer.github.io/SectionCV/

## วิธีเล่น

1. กด **เริ่มเกม** เพื่อเริ่มนับเวลา
2. แตะจุดต่างในภาพใดก็ได้ จุดที่พบจะแสดงวงสีแดงทั้งสองภาพและนับคะแนนเพียงครั้งเดียว
3. ใช้คำใบ้ได้ 2 ครั้ง แต่ละคำใบ้จะชี้ไปยังจุดที่ยังไม่พบและไม่ซ้ำกัน
4. กด **หยุดพัก** หรือสลับไปแอปอื่นเพื่อพักเวลา กด **เล่นต่อ** เพื่อกลับมาเล่น
5. เมื่อพบครบหรือหมดเวลา จะมีหน้าสรุปผล กด **เล่นอีกครั้ง** เพื่อเริ่มรอบใหม่ หรือ **กลับไปดูภาพ** เพื่อดูจุดที่เหลือ

ปุ่มเสียงเปิดเสียงเอฟเฟกต์จริงผ่าน Web Audio หลังผู้เล่นกดเปิดเสียง หากอุปกรณ์ไม่รองรับเสียง เกมยังเล่นได้ตามปกติ

## เปิดจากเครื่องโดยไม่ต้องติดตั้งอะไร

- Windows: ดับเบิลคลิก `start.bat`
- macOS / Linux: รัน `./start.sh`
- ทุกระบบ: เปิด `index.html` ด้วยเบราว์เซอร์ได้โดยตรง

ไม่ต้องเปิดเซิร์ฟเวอร์หรือใช้ Python จึงไม่ต้องเปิดหน้า `localhost:8000` และไม่ต้องเปิด Terminal ค้างไว้ ภาพอยู่ในไฟล์เกม ส่วนฟอนต์ออนไลน์มีฟอนต์สำรองของเครื่อง

## การทดสอบและเตรียมไฟล์เผยแพร่

ใช้ Node.js 24 ขึ้นไปเฉพาะสำหรับงานพัฒนา:

```bash
npm ci --ignore-scripts
npm test
npm run build
```

ชุดทดสอบใช้ DOM จำลองและนาฬิกาควบคุม ตรวจการเริ่มเกม การเลือกจุดในสองภาพ คำใบ้ การหยุดพัก การสลับแอป การหมดเวลา การเล่นซ้ำ การควบคุมหน้าสรุปด้วยคีย์บอร์ด และการเรียกใช้เสียง รวมถึงตรวจว่าภาพต่างกันเพียง 5 จุดและตำแหน่งแตะไม่บังกันที่ขนาดภาพสำหรับมือถือกับคอมพิวเตอร์

การทดสอบนี้ไม่ได้จำลองการวาดภาพหรือฮาร์ดแวร์เสียงของอุปกรณ์จริง

`npm run build` คัดลอกเฉพาะไฟล์สาธารณะไปยัง `_site/` โดยเก็บลิงก์เกมจับคู่เดิมไว้ทั้ง `memory-game/` และ `docs/memory-game/`

## GitHub Pages

Workflow `Deploy Makro game to GitHub Pages` ทดสอบเกมก่อนเผยแพร่เมื่อ push ไปยัง `main`, `work` หรือ `codex/create-makro-sprite-spot-the-difference-game` และเรียกเองได้จาก Actions

ใน **Settings → Pages → Source** ให้เลือก **GitHub Actions** สำหรับ workflow นี้ จากนั้นเปิดลิงก์ในงาน deployment ที่สำเร็จ

Workflow `Verify Makro game` รันชุดทดสอบใน Pull Request ด้วย โค้ดเกมไม่ต้องใช้บัญชีผู้เล่นหรือเซิร์ฟเวอร์เบื้องหลัง
