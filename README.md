# Makro Spot the Difference

เกมจับผิดภาพธีมซูเปอร์มาร์เก็ต รองรับการเล่นบนเดสก์ท็อปและมือถือ ผู้เล่นต้องค้นหาจุดแตกต่าง 5 จุดก่อนหมดเวลา 2 นาที

## เริ่มใช้งาน

```bash
python3 -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000`

## ความสามารถ

- ภาพเกมวาดด้วย SVG โหลดเร็วและคมชัดทุกหน้าจอ
- จุดแตกต่างแบบโต้ตอบพร้อมเอฟเฟกต์เมื่อเลือกถูกหรือผิด
- ตัวจับเวลา แถบความคืบหน้า และสรุปผลเมื่อจบเกม
- คำใบ้ 2 ครั้งต่อเกม
- เริ่มเล่นใหม่ได้ทันที
- รองรับหน้าจอเดสก์ท็อป แท็บเล็ต และมือถือ
