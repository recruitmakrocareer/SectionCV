# Makro Spot the Difference — 3 Photo Levels

เกมจับผิดภาพเสมือนจริงในซูเปอร์มาร์เก็ต 3 ด่าน ด่านละ 5 จุด รวม 15 จุด เล่นด้วยเมาส์หรือแตะได้ทั้งสองภาพ

เล่นออนไลน์: https://recruitmakrocareer.github.io/SectionCV/

## เพิ่มระบบผู้เล่นและอันดับ

หน้าเริ่มเกมแสดงเป็นป๊อปอัปทันที กดผิดเพิ่มเวลาจัดอันดับครั้งละ 5 วินาที โดยไม่เพิ่มเวลาที่เหลือให้เล่น

เพิ่มเซิร์ฟเวอร์ LINE Login, แบบฟอร์มชื่อ/เบอร์ติดต่อ, อันดับรวม 10 คนที่เวลาน้อยที่สุด และหน้าข้อมูลผู้เล่นสำหรับผู้ดูแลพร้อมส่งออก CSV แล้ว โค้ดและการทดสอบอยู่ในโครงการนี้ แต่ **LINE Login และการเก็บอันดับจริงยังต้องตั้งค่า Channel และโฮสต์เซิร์ฟเวอร์ก่อน** เว็บ GitHub Pages ปัจจุบันจึงให้เล่นแบบฝึกซ้อม ไม่แสดงสถิติจำลองหรือเก็บข้อมูลส่วนตัวไว้เฉพาะเครื่อง

ดูขั้นตอนเปิดใช้งานและข้อกำหนดการเก็บข้อมูลใน [SETUP-LINE.md](SETUP-LINE.md)

เลือกใช้ **Cloudflare Workers Free + D1 Free** ตามที่ผู้ดูแลต้องการ ไม่มีค่าเช่าเครื่องรายเดือนและใช้ URL `workers.dev` ที่ให้ฟรี ไฟล์ [wrangler.json](wrangler.json) ใช้ชื่อ `sectioncv` ตรงกับ Worker ที่ผู้ดูแลสร้างแล้ว ยังต้องเปลี่ยนสาขา deploy เป็นสาขาเกม, เชื่อม D1, กรอก Channel Secret ที่โฮสต์ และตั้ง Callback URL ใน LINE ก่อนเปิดรับผู้เล่นจริง ดู [วิธีติดตั้งแบบไม่มีค่าใช้จ่าย](SETUP-LINE.md)

แพ็กเกจ Free มีโควตา API 100,000 คำขอต่อวัน และฐานข้อมูลนี้สูงสุด 500 MB ไม่อัปเกรดเป็น Paid เพื่อรองรับการใช้งานเกินโควตา ดูขีดจำกัดการอ่าน/เขียนและแหล่งข้อมูลในคู่มือติดตั้ง

## ด่านในเกม

1. **โซนผักและผลไม้** — สังเกตความต่างของผลไม้และผักในแผงสินค้า
2. **มุมเบเกอรี่อบสด** — สังเกตรอยบนขนมและรายละเอียดของหน้าขนม
3. **ชั้นเครื่องปรุงและของแห้ง** — หารายละเอียดเล็ก ๆ ท่ามกลางขวดและกระปุกที่คล้ายกัน

ภาพเป็นภาพเสมือนจริงที่สร้างขึ้นสำหรับเกมด้วย Imagegen ไม่ใช่ภาพการ์ตูน

## วิธีเล่น

- รอภาพพร้อมแล้วกด **เริ่มด่าน** แต่ละด่านมีเวลา 2 นาที และคำใบ้ 2 ครั้ง
- แตะจุดต่างในภาพใดก็ได้ คะแนนเดียวกันจะนับเพียงครั้งเดียว และวงคำตอบจะแสดงทั้งสองภาพ
- ผ่านด่านแล้วกด **ไปด่านถัดไป** เมื่อครบ 3 ด่านจะสรุปผลรวม 15 จุดและเวลาที่ใช้
- โหมดฝึกซ้อม: หากหมดเวลาเลือก **ลองด่านนี้อีกครั้ง** ได้ ส่วนรอบจัดอันดับต้องเริ่มใหม่ทั้ง 3 ด่าน
- ปุ่ม **เริ่มด่านนี้ใหม่** รีเซ็ตเฉพาะด่านปัจจุบัน ส่วน **เริ่มใหม่ทั้ง 3 ด่าน** จะปรากฏหลังผ่านเกมทั้งหมด
- กด **หยุดพัก** หรือสลับไปแอปอื่นเพื่อพักเวลา กด **เล่นต่อ** เพื่อกลับมาเล่น
- บนมือถือใช้สองนิ้วซูมหน้าเกมเพื่อดูรายละเอียดได้
- ปุ่มเสียงเปิดเสียงเอฟเฟกต์จริง หากอุปกรณ์ไม่รองรับเสียงยังเล่นเกมได้ตามปกติ

ภาพต้องโหลดครบก่อนเริ่มนับเวลา หากภาพโหลดไม่สำเร็จจะมีปุ่มลองโหลดอีกครั้ง

## เปิดจากเครื่อง

- Windows: ดับเบิลคลิก `start.bat`
- macOS / Linux: รัน `./start.sh`
- ทุกระบบ: เปิด `index.html` ด้วยเบราว์เซอร์ได้โดยตรง โดยเก็บไฟล์อื่นและโฟลเดอร์ `assets/` ไว้ด้วยกัน

ไม่ต้องเปิดเซิร์ฟเวอร์หรือใช้ Python ฟอนต์ออนไลน์มีฟอนต์สำรองของเครื่อง

## การทดสอบและเผยแพร่

ใช้ Node.js 24 ขึ้นไปเฉพาะสำหรับงานพัฒนา:

```bash
npm ci --ignore-scripts
npm test
npm run build
```

ชุดทดสอบใช้ DOM จำลองและนาฬิกาควบคุม ตรวจการโหลดภาพ/ลองใหม่ การเล่นครบ 3 ด่าน การลองด่านที่แพ้ซ้ำ การเริ่มเกมใหม่ คำใบ้ การหยุดพัก การหมดเวลา เสียง คีย์บอร์ด และตำแหน่งแตะหลายขนาดหน้าจอ การทดสอบนี้ไม่จำลองการวาดภาพหรือฮาร์ดแวร์เสียงของอุปกรณ์จริง

`levels.js` กำหนดภาพและตำแหน่ง 5 จุดของแต่ละด่าน ภาพทั้งสองฝั่งใช้ภาพต้นฉบับเดียวกัน แล้วแสดงภาพที่แก้ไขเฉพาะ 5 บริเวณด้วย mask ขอบนุ่ม เพื่อป้องกันรายละเอียดอื่นจากการสร้างภาพกลายเป็นจุดต่างนอกเกม

`image-generation.json` เก็บ prompt และข้อมูลอ้างอิงของภาพสำหรับแก้ไขต่อ โดยไม่ได้รวมในไฟล์เผยแพร่

ชุดทดสอบ Cloudflare ใช้ Miniflare/workerd และ D1 จริงในเครื่อง ตรวจ OAuth จำลอง, คำขอพร้อมกัน, การบันทึกซ้ำ, สิทธิ์ข้อมูลส่วนตัว, การเล่นผ่านหน้าเกมครบสามด่าน และข้อมูลคงอยู่หลังเริ่มระบบใหม่ ยังต้องทดสอบ LINE จริงก่อนเปิดกิจกรรม

`npm run check:worker` ตรวจชุดเผยแพร่ Cloudflare โดยไม่สร้างบริการหรือใช้ข้อมูลจริง

`npm run build` สร้าง `_site/` ใหม่จากรายการไฟล์เกมและภาพที่อนุญาตเท่านั้น และรักษาลิงก์เกมจับคู่เดิมที่ `memory-game/` กับ `docs/memory-game/`

Workflow `Deploy Makro game to GitHub Pages` รันชุดทดสอบก่อนเผยแพร่เมื่อ push ไปยัง `main`, `work` หรือ `codex/create-makro-sprite-spot-the-difference-game` ส่วน `Verify Makro game` ตรวจใน Pull Request ด้วย
