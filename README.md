# SectionCV

เว็บสำหรับเปลี่ยนข้อมูลผู้สมัครจาก Google Sheets/TSV ให้เป็น Resume Workspace ที่ค้นหา กรอง เปิดดูรายละเอียด และแสดงความคิดเห็นร่วมกันได้

## เริ่มใช้งาน

```bash
python3 -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000`

## ความสามารถ

- นำเข้าข้อมูลผู้สมัครแบบ TSV
- เชื่อมชีตคำตอบของ Google Form ผ่านลิงก์ Google Sheets และซิงก์อัตโนมัติ
- ค้นหาและกรองตามสาขาหรือสถานะ
- แสดงผลแบบการ์ดและรายการ
- ดู Resume และข้อมูลติดต่อในแถบด้านข้าง
- เพิ่มความคิดเห็นสำหรับผู้สมัครแต่ละคน
- รองรับหน้าจอเดสก์ท็อปและมือถือ

> ข้อมูลตัวอย่างบางส่วนถูกปกปิดเพื่อความเป็นส่วนตัว และข้อมูลที่นำเข้าจะอยู่ในหน่วยความจำของเบราว์เซอร์เท่านั้น

## เชื่อม Google Form

1. เปิด Google Form แล้วไปที่แท็บ **คำตอบ** และกดไอคอน Google Sheets เพื่อสร้างชีตคำตอบ
2. ใน Google Sheets กด **แชร์** และตั้งค่าการเข้าถึงทั่วไปเป็น **ทุกคนที่มีลิงก์ — ผู้มีสิทธิ์อ่าน**
3. คัดลอก URL ของชีต แล้วกด **นำเข้าผู้สมัคร** ใน SectionCV
4. วาง URL ในแท็บ **Google Form / Sheets** กด **ตรวจสอบการเชื่อมต่อ** แล้วกด **นำเข้าข้อมูล**

เมื่อเลือก “จดจำลิงก์นี้” เว็บจะบันทึกลิงก์ไว้ใน `localStorage` และดึงคำตอบใหม่เมื่อเปิดหน้าเว็บครั้งถัดไป โดยระบบจะข้ามผู้สมัครที่มีอีเมลและตำแหน่งซ้ำกัน
