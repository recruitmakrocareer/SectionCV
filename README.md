# SectionCV

เว็บสำหรับเปลี่ยนข้อมูลผู้สมัครจาก Google Sheets/TSV ให้เป็น Resume Workspace ที่ค้นหา กรอง เปิดดูรายละเอียด และแสดงความคิดเห็นร่วมกันได้

## เริ่มใช้งาน

```bash
python3 -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000`

## ความสามารถ

- นำเข้าข้อมูลผู้สมัครแบบ TSV
- ค้นหาและกรองตามสาขาหรือสถานะ
- แสดงผลแบบการ์ดและรายการ
- ดู Resume และข้อมูลติดต่อในแถบด้านข้าง
- เพิ่มความคิดเห็นสำหรับผู้สมัครแต่ละคน
- รองรับหน้าจอเดสก์ท็อปและมือถือ

> ข้อมูลตัวอย่างบางส่วนถูกปกปิดเพื่อความเป็นส่วนตัว และข้อมูลที่นำเข้าจะอยู่ในหน่วยความจำของเบราว์เซอร์เท่านั้น
