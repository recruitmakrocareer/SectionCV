# Makro Spot the Difference

เกมจับผิดภาพธีมซูเปอร์มาร์เก็ต รองรับการเล่นบนเดสก์ท็อปและมือถือ ผู้เล่นต้องค้นหาจุดแตกต่าง 5 จุดก่อนหมดเวลา 2 นาที

## เริ่มใช้งานแบบเร็วที่สุด

### Windows

ดับเบิลคลิกไฟล์ `start.bat` ระบบจะเปิดเบราว์เซอร์ไปยังเกมให้อัตโนมัติ **อย่าปิดหน้าต่าง Command Prompt ระหว่างเล่น**

### macOS / Linux

```bash
./start.sh
```

จากนั้นเปิด `http://localhost:8000` และเปิด Terminal ค้างไว้ระหว่างเล่น

หากยังไม่ได้ให้ใช้คำสั่งต่อไปนี้จากภายในโฟลเดอร์โปรเจกต์:

```bash
python3 -m http.server 8000
```

หรือสามารถดับเบิลคลิก `index.html` เพื่อเล่นแบบไม่เปิดเว็บเซิร์ฟเวอร์ได้

## Deploy บน GitHub Pages

โปรเจกต์มี GitHub Actions workflow สำหรับ deploy ให้อัตโนมัติแล้ว เมื่อ push branch `main` หรือ `work` ขึ้น GitHub:

1. เปิด **Settings → Pages** ใน repository
2. เลือก Source เป็น **GitHub Actions**
3. Push branch `main` หรือ `work`
4. ดู URL ของเกมได้จากหน้า **Actions** หลัง workflow `Deploy Makro game to GitHub Pages` ทำงานสำเร็จ

## แก้ปัญหา `ERR_CONNECTION_REFUSED`

ข้อความนี้หมายความว่าเว็บเซิร์ฟเวอร์ยังไม่ได้เปิด หรือหน้าต่าง Terminal ที่เปิดเซิร์ฟเวอร์ถูกปิดไปแล้ว ให้ทำดังนี้:

1. เปิดโฟลเดอร์โปรเจกต์ `SectionCV`
2. ดับเบิลคลิก `start.bat` (Windows) หรือรัน `./start.sh` (macOS/Linux)
3. เปิดหน้าต่าง Terminal/Command Prompt ค้างไว้
4. Reload หน้า `http://localhost:8000`

## ความสามารถ

- ภาพเกมวาดด้วย SVG โหลดเร็วและคมชัดทุกหน้าจอ
- จุดแตกต่างแบบโต้ตอบพร้อมเอฟเฟกต์เมื่อเลือกถูกหรือผิด
- ตัวจับเวลา แถบความคืบหน้า และสรุปผลเมื่อจบเกม
- คำใบ้ 2 ครั้งต่อเกม
- เริ่มเล่นใหม่ได้ทันที
- รองรับหน้าจอเดสก์ท็อป แท็บเล็ต และมือถือ
